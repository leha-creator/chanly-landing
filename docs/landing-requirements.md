## Поведение девяти блоков

Общее правило для блоков 3–9: при первом достижении секции плавно появляется заголовок, затем по очереди её элементы. Для всех этих секций используются общие длительность, смещение, кривая движения и интервал между элементами. Показанное содержимое остаётся видимым. Прокрутка назад, переход по якорю и возврат на главную внутри приложения сохраняют состояние. Перезагрузка страницы начинает показ заново.

| Блок | Критерий приёмки |
| --- | --- |
| 1. Первый экран | После загрузки элементы плавно появляются один раз. Затем крупный логотип первого экрана бесконечно и плавно плавает по вертикали с ходом 15–20 px. До 48rem включительно шапка с навигацией находится в начале документа и уходит при прокрутке. Выше 48rem шапка закреплена сверху. Вступление повторяется только после перезагрузки. |
| 2. Лента | «КОНТЕНТ», «АУДИТОРИЯ», «РЕКЛАМА», «ДОХОД» и остальные надписи начинают медленно двигаться слева направо после загрузки. На границе циклов скорость и интервалы сохраняются, без скачка, пустого участка или паузы. |
| 3. «У канала есть голос. Пусть будет и доход.» | Три графитовые карточки с примерами запроса, цены и расписания появляются в порядке чтения. На телефоне образуют одну колонку. |
| 4. «От подключения канала до первой выплаты» | После общего появления выбор вкладки слева меняет скриншот и активный нижний переключатель. Выбор снизу также обновляет вкладку. При ширине более 64rem и обычном движении четыре шага переключаются каждые 20 секунд. До 64rem включительно и при уменьшенном движении пользователь переключает их вручную. Смена ширины сохраняет шаг. После ручного выбора пользователь получает полные 20 секунд на новый скриншот. |
| 5. «Сколько может приносить ваш канал?» | После общего появления пользователь выбирает тематику и меняет исходные данные. Итог обновляется сразу. В интерфейсе отсутствуют поле цены, ставка, формула и пояснения с их значениями. |
| 6. «Понятные условия. Спокойная работа.» | Четыре вытянутые карточки с узорами расположены со смещением. Четвёртая карточка фиолетовая. На телефоне карточки идут вертикально. |
| 7. Ответы на вопросы | После общего появления нажатие на вопрос плавно раскрывает ответ. Открытие другого вопроса сворачивает предыдущий. Одновременно раскрыт максимум один ответ. |
| 8. Связь | Секция появляется по общему правилу. Единственную форму собрать из Vue-компонентов. Проверить ввод, фокус, ошибки отдельных полей, отправку, успех и сбой. Ошибка сохраняет введённый текст. Успех показывать после подтверждения доставки. |
| 9. Подвал | Элементы появляются по общему правилу. Каждая внутренняя ссылка плавно прокручивает страницу к соответствующей секции. |

### Калькулятор

Единица внутренней ставки — рубли за **1 000 просмотров**. Для чернового справочника предусмотреть 15–30 тематик. Начальные примеры: «Открытки / поздравления» — 0,30 ₽, «Дача / дом» — 0,35 ₽, «Новости и СМИ» — 0,65 ₽. Остальным тематикам случайно назначить ставку от 30 до 100 копеек при подготовке справочника. Сохранить назначенные значения для последующей ручной модерации. Одинаковые вводные должны давать одинаковый результат, в том числе после переключения тематики туда и обратно.

Контрольный пример при 10 000 просмотров за расчётный период: 3 ₽ для открыток, 3,50 ₽ для дома и 6,50 ₽ для новостей. Это внутренний пример для проверки. Нулевой объём даёт нулевой доход. Для некорректного ввода поле показывает ошибку.

## Общие компоненты и движение

- **Стили.** В общей теме хранить семантические цвета, типографику, отступы, радиусы, уровни наложения и параметры движения. Секции собираются из переиспользуемых Vue SFC. Их локальные SCSS-стили опираются на тему. Общие кнопки и поля поддерживают наведение, видимый фокус, нажатие и отключённое состояние, кнопки действий — также загрузку, поля — ошибку с пояснением.
- **Прокрутка.** Использовать Lenis с интеграцией для Vue. Медленную плавную прокрутку страницы, якоря шапки и подвала и возврат наверх обслуживает один экземпляр. Целевой заголовок остаётся виден под шапкой. Проверить прокрутку колесом, касанием и клавиатурой. При включённом уменьшении движения сохранить доступ к контенту и навигации без декоративных циклов и замедления. [Документация Lenis для Vue](https://github.com/darkroomengineering/lenis/blob/main/packages/vue/README.md)
- **Возврат наверх.** Стрелка закреплена слева внизу. На первом экране она скрыта, появляется при достижении второго блока и по нажатию возвращает к первому экрану.
- **Подключение канала.** Все одноимённые кнопки вызывают единое действие перехода на страницу авторизации сервиса. До получения адреса допустима заглушка с `console.log`. Проверять отдельно на этапе интеграции.
- **Уведомления.** Тосты размещаются справа, стрелка слева, баннер по центру. В узком окне стрелка и тосты стоят над баннером и опускаются после его закрытия. У каждого тоста есть кнопка закрытия и собственный таймер на 10 секунд.
- **Cookie.** «Принять» сохраняет выбор в этом браузере. «Отклонить» закрывает баннер до следующего посещения. При запрете хранилища кнопки продолжают работать.

## Выпуск

В GitHub Actions проверять код, ключевые сценарии и production-сборку. Публиковать на существующий сервер только артефакт успешной проверки. Перед настройкой доставки уточнить домен, способ доступа и каталог публикации. После выкладки проверить HTTPS, загрузку ресурсов, прямое открытие маршрутов и возможность отката. Для подключения реальных действий потребуются адрес авторизации и способ доставки контактной формы.
