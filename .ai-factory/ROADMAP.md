# Дорожная карта Chanly

> Выпустить публичный лендинг Chanly по макету Figma и подготовить основу для следующих страниц сайта.

## Этапы

- [x] **Контекст проекта.** Согласованы стек Vue и плоская архитектура, сохранены настройки проекта и ссылка на дизайн.
- [x] **Настольный макет и прототип V3.4.** Проверить доступ к макету V3.4 на странице Figma «Лендинг · правки 04», внести визуальные правки и подготовить состояния компонентов и сценарии движения.
- [x] **Мобильный макет V3.4.** До начала вёрстки адаптировать все девять блоков настольного V3.4, навигацию и закреплённые элементы для узкого экрана. Сохранить прямые ссылки на оба итоговых фрейма в критериях приёмки.
- [x] **Компоненты, стили и непрерывная интеграция.** Подготовить Vue-приложение, общие SCSS-переменные и компоненты. В GitHub Actions проверять изменения и собирать сайт на каждый pull request.
- [x] **Адаптивная страница, движение и навигация.** Собрать девять блоков, шапку и подвал. Реализовать общий порядок появления секций, анимации первого экрана и ленты, плавную прокрутку, якоря и возврат наверх.
- [x] **Демонстрация сервиса и оценка дохода.** Синхронизировать вкладки, скриншоты и автопоказ. Реализовать интерактивный расчёт по тематике канала.
- [x] **Ответы на вопросы и обратная связь.** Реализовать аккордеон, контактную форму, общую систему уведомлений и предупреждение о cookie.
- [x] **Приёмка лендинга.** Сверить настольную и мобильную вёрстку с соответствующими итоговыми фреймами V3.4. Проверить сценарии мышью, касанием и клавиатурой, таймеры, результаты калькулятора и режим уменьшенного движения.
- [x] **Публикация через GitHub Actions.** Доставить прошедшую проверки сборку на существующий сервер, проверить сайт на действующем домене и возможность вернуть предыдущую сборку.

Параметры анимаций, правила расчёта и сценарии проверки приведены в [критериях приёмки](../docs/landing-requirements.md).
