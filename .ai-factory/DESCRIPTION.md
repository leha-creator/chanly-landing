# Публичный сайт Chanly

Первый выпуск — лендинг продукта Chanly. В дальнейшем сайт может получить самостоятельные страницы с общей навигацией. Лендинг разрабатывается отдельно от приложения в `D:\work\maxim-frontend`.

## Дизайн

Реализуем макет **V3.4** со страницы **«Лендинг · финал V3.4»** в файле [Chanly Landing в Figma](https://www.figma.com/design/GABqUBOTgsEbLEfXUkrsJy/Chanly-Landing). Он определяет состав секций, тексты и изображения. Прямые ссылки на настольный и мобильный макеты для вёрстки собраны в [критериях приёмки](../docs/landing-requirements.md).

Для чтения макета в Codex настроен проектный MCP-сервер `figma`. При первом подключении выполните `codex mcp login figma` под учётной записью с доступом к файлу.

## Стек

Vue 3, Single-File Components с Composition API, SCSS для стилей компонентов, Vue Router для страниц и Pinia для общего состояния. Библиотеку анимации выбирайте под конкретный эффект с учётом поддержки проекта, управления воспроизведением и стоимости загрузки.

## Архитектура

При push в dev GitHub Actions публикует проверенный пакет по SSH на dev.chanly.ru. При push в master собирает пакет для chanly.ru и сохраняет его как артефакт. За внешним Basic Auth корень домена показывает лендинг гостю или открывает приложение по действующей сессии. Выпуск и откат описаны в [README](../README.md).

Сборка — Vite, проверки — ESLint и Vitest с Vue Test Utils. Шрифты Manrope, Inter и Lora поставляются локально через Fontsource. Плавная прокрутка использует Lenis с Vue-интеграцией. Команды разработки и сборки описаны в [README](../README.md).

Сайт использует плоскую структуру Vue. Размещение компонентов, стилей и маршрутов описано в [архитектуре проекта](ARCHITECTURE.md).
