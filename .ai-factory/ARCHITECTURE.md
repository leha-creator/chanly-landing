# Плоская архитектура Vue

В основе структуры лежит назначение файла. Главная страница собирает секции лендинга, а общий каркас сайта отвечает за шапку, навигацию и подвал. Такой каркас можно использовать и для следующих страниц. Основа решения — раздел «Плоская» в [Vue FAQ](https://vue-faq.org/ru/development/architectural-patterns.html).

## Целевая структура

Каталоги появляются вместе с первым файлом соответствующего назначения.

| Путь внутри `src/` | Назначение |
| --- | --- |
| `App.vue` | Общий каркас и место вывода текущего маршрута |
| `layout/` | Шаблон страницы с общей шапкой и подвалом |
| `views/` | Компонент на каждый самостоятельный адрес сайта |
| `components/` | Секции и элементы интерфейса |
| `composables/` | Повторно используемая логика Composition API |
| `router/` | Маршруты Vue Router |
| `stores/` | Общее реактивное состояние Pinia |
| `assets/` | Изображения, шрифты и общие SCSS-стили |

## Границы компонентов

На dev.chanly.ru Caddy выбирает документ для корня по результату проверки сессии. Vite собирает ресурсы лендинга в `/landing-assets/`. Переход из Vue на `/auth/login` загружает документ React-приложения. Выпуском и возвратом статического пакета управляет [обработчик SSH](../deploy/release.py).

Страница определяет состав и порядок секций. Компонент получает данные через props и сообщает о действиях через события. Общий компонент должен работать на любой странице, которая передаёт ему нужные данные. Вызовы библиотеки анимации держите рядом с владельцем эффекта и освобождайте ресурсы при размонтировании.

## Добавление страницы

Для нового самостоятельного раздела создайте SFC в `views/` и зарегистрируйте маршрут. Например, при появлении страницы компании запись маршрута может выглядеть так:

```js
{ path: '/company', component: () => import('../views/CompanyView.vue') }
```

Vue Router подставит страницу в общий каркас:

```vue
<SiteLayout>
  <RouterView />
</SiteLayout>
```

Переход к секции уже открытой страницы оформляйте якорной ссылкой. При публикации новых маршрутов проверяйте прямой вход и обновление страницы по каждому адресу.
