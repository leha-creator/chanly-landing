## Settings

- Режим: full, один файл. Работа в текущей ветке master.
- Commit strategy: incremental
- Development methodology: implementation-first
- Tests: yes — адресные регрессии.
- Docs: yes — ссылки на макеты и актуальные критерии приёмки.
- Logging: minimal — WARN/ERROR только при неисправности, если её уже обрабатывает приложение. Для всех задач ниже обычные взаимодействия, выбор cookie, ввод и действия формы не логировать.
- Решение пользователя после исходного запроса: на телефонах и планшетах шаги переключаются только вручную. Для реализации предложена граница 64rem (1024 CSS px при базовых 16 px) для демо; другие блоки сохраняют собственные адаптивные правила.
