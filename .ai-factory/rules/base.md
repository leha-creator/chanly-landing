# Соглашения для первого этапа

Первые компоненты пишите как Vue SFC с `<script setup>`. Размещайте стили компонента в `<style scoped lang="scss">`. Общую типографику и переменные дизайна храните в стилях сайта.

Используйте локальное состояние для взаимодействий внутри одного компонента. Выделяйте хранилище Pinia, когда нескольким частям сайта нужны одни и те же данные и действия.

Для анимаций учитывайте настройку `prefers-reduced-motion`. Основное содержимое должно быть доступно и при отключённом движении.
